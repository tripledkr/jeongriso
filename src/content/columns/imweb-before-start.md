아임웹 홈페이지 제작을 시작하기 전에 조금만 정리해 두면, 만드는 시간도 줄고 결과물도 훨씬 좋아집니다. **도구를 열기 전에 먼저 정리할 6가지**를 순서대로 소개합니다.

## 1. 홈페이지의 목적 한 문장

"우리 홈페이지를 본 사람이 결국 무엇을 하길 바라는가?"를 한 문장으로 적어 보세요.

- 문의를 남기게 하고 싶다
- 회사를 믿을 수 있게 소개하고 싶다
- 예약이나 구매로 이어지게 하고 싶다

목적에 따라 메인 화면에서 가장 먼저 보여줄 내용과 버튼 위치가 달라집니다.

## 2. 메뉴 구조 초안

처음부터 완벽할 필요는 없습니다. 종이에 메뉴 이름만 적어 봐도 충분합니다. 일반적인 회사 홈페이지는 아래 구성에서 시작합니다.

| 메뉴 | 들어갈 내용 |
| --- | --- |
| 회사소개 | 하는 일, 강점, 연혁 |
| 서비스 | 서비스별 설명 |
| 실적 | 프로젝트, 고객사 |
| 소식 | 공지, 칼럼 |
| 문의 | 문의폼, 연락처, 오시는 길 |

## 3. 회사 자료 모으기

회사소개서, 로고, 사진, 실적 목록을 한 폴더에 모아 두세요. 자료가 정리되어 있지 않아도 괜찮습니다. **있는 것을 한곳에 모으는 것**이 첫 단계입니다.

## 4. 참고하고 싶은 홈페이지

마음에 드는 홈페이지 2~3개의 주소를 모아 두고, 각각 어떤 점이 좋았는지 한 줄씩 적어 두세요. 같은 업종이 아니어도 됩니다. 원하는 분위기를 설명하는 가장 빠른 방법입니다.

## 5. 도메인 준비

회사 이름이나 서비스 이름으로 된 도메인이 있는지 확인하세요. 이미 가지고 있다면 어디서 구매했는지, 관리 계정은 누구 것인지 함께 정리해 두면 연결할 때 헤매지 않습니다.

## 6. 오픈 후 운영 담당자

누가 홈페이지를 고칠지 미리 정해 두세요. 담당자가 정해져 있으면 그 사람이 쓰기 편한 구조로 만들 수 있고, 오픈할 때 사용법도 그 사람 중심으로 익히면 됩니다.
